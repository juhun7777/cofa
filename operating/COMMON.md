# 공통 원칙 — T1 정리 / T2·T3 구현 / T4 설명

2026-11-05 개정. 이전 T1 구현·T3 설명 구성과 섞지 않는다. 일반 Markdown 지침이며 실제 과제·플랫폼·기존 프로젝트 지침이 우선이다.

1. 프로젝트 루트·허용 도구·제출 조건을 확인한다. 시간은 사용자가 관리하며 남은 시간·종료 시각을 필수 입력·기록으로 요구하거나 자동 추정하지 않는다. 준비 저장소와 실제 소스 위치를 구분한다. 실제 기록은 허용된 프로젝트 작업 폴더에 두며 기본 예시는 `_work/`다.
2. T1은 전체 이해·출처 표·요구·실무자 질문·답변·변경 영향·상태를 관리한다. 제품 구현과 전체 테스트를 기본 업무로 맡지 않는다. 중요한 선택은 사용자가 근거와 대가를 이해하고 판단하도록 돕는다.
3. T2·T3는 구현 A/B를 나눠 담당 부분의 상세 분석→구현→기본·경계·실패 검사→수정을 수행한다. T2는 지정된 뼈대·공통 계약·기술 통합을 관리할 수 있지만 모든 수정이 T2에 몰리지 않게 한다.
4. T4는 실제 코드·결정·검증 기록을 근거로 현재 구현의 위치·흐름·원리·확인된 선택 이유·한계를 설명한다. 제품 소스·전체 테스트를 기본 역할로 맡지 않는다. 설명을 검증 증거로 취급하지 않는다.
5. 기록 폴더가 허용되면 각 작성자가 자기 기록이 없을 때 생성한다. 작성자는 T1→STATE.md, T2→T2.md, T3→T3.md, T4→UNDERSTANDING.md로 나눈다. 기존 기록은 먼저 읽고 필요한 부분만 갱신하며 원본 README·데이터 설명을 대신 덮어쓰지 않는다. 규모가 작으면 설명을 T1이 겸할 수 있지만 구현자 두 명이 필요한 일을 다시 한 명에게 몰지 않는다.
6. 초기 읽기는 과제·규칙·제출 → 데이터 설명·실제 구조 → 관련 기존 코드·실행 경로 순서로 나눠 수행한다. 긴 문서는 절 단위로 읽고 미확인 범위를 표시한다. 필수 조건에는 파일·절·줄 등 출처를 붙인다. 전 소스를 무제한 정독하지 않는다.
7. 독립 터미널의 대화와 파일 갱신은 자동 전달되지 않는다. 중요한 변경 때 읽을 경로·새 사실·필요 행동을 짧게 전달한다. 반복 감시·자동 통신 프로그램을 새로 만들지 않는다.
8. 구현 전 STATE의 같은 작업약속 ID를 읽는다. 담당 기능·수정/금지 파일, 입력·출력 예시, 실패·부분 성공 표현, 실제 완료 기준, 공통 파일·테스트·DB·포트 작성자를 명시한다. T2·T3는 자기 범위와 상대 범위를 짧게 확인하고 지정 범위만 수정한다. 범위 누락·중복·계약 충돌이 있으면 영향받는 쓰기만 보류하고 T1·기술 담당에게 확인한다. 상대 소스는 임의 수정하지 않는다.
9. 원본 README·데이터를 덮어쓰지 않는다. 제공 스택·기존 코드를 활용한다. 요구되지 않은 인증·DB·큐·배포·플러그인·하네스를 만들지 않는다. 결정된 범위의 통상 구현은 반복 승인을 요구하지 않는다.
10. 작은 실제 입력의 전체 흐름을 일찍 연결하고 필수 요구를 완성한다. 임시 데이터·목업을 실제 연동 완료로 보고하지 않는다. 필수 제약을 임의 완화하거나 선택 사항으로 바꾸지 않는다.
11. T2·T3는 핵심 계산·필수 제약·계약 경계를 원문·원자료·수계산·독립 기준으로 나눠 교차 확인한다. 자기 코드 실행이나 다른 AI의 동의만으로 정확성을 주장하지 않는다. 입력·기대·근거·실제·대상 상태·확인 주체를 기록한다.
12. 질문 후보는 누구나 찾되 T1이 원문·중복·영향을 확인해 사용자에게 제안한다. 업무 정책·데이터 의미는 실무자, 코드 동작은 구현·실행, 선택 이유는 실제 결정 기록에서 확인한다. 실제 질문·답변 전달은 사용자가 한다.
13. 변경될 때 필요한 표·결정·구현·설명만 갱신한다. 장문 중복 정리·무한 리뷰·끝없는 질문을 하지 않는다. 이유·동의·검증·사용자 이해를 지어내지 않는다. 사실·추정·미확인·향후 개선을 구분한다.
14. operating 안의 일반 Markdown 지침을 직접 읽어 사용한다. 별도 등록·설치는 하지 않는다. 허용되지 않은 업데이트·도구·외부 전송을 우회하지 않는다. 실제 문제·데이터·기록·결과를 공개 저장소에 쓰거나 Push하지 않는다. AI 금지 단계에서는 설명·파일 읽기·도구 실행을 포함해 지원을 멈춘다.
