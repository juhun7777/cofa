# 반복 업무·워크플로우

현재 수작업 흐름의 입력·판단·출력을 구분하고 실제 병목만 자동화한다. 승인·검수는 오류 비용이 있거나 과제에서 요구할 때 둔다.

파일 처리라면 원본 보존과 별도 출력 위치, 실패 파일 식별, 중복 실행의 영향을 고려한다. 외부 호출이라면 타임아웃·명시적 실패 상태와 필요한 만큼의 제한된 재시도를 둔다. 재시도가 중복 처리·중복 저장을 만들 수 있으면 그것부터 제어한다.

전체 시스템 대신 작은 표본으로 입력 한 건이 출력 한 건으로 이어지는 과정을 확인한다. 일부 실패를 전체 성공으로 표시하지 말고 처리·제외·실패 건수를 대조한다. 실제 외부 전송·업로드·메시지 발송·배포는 시험 규칙에 명시적으로 허용된 경우에만 수행한다.

브라우저·OS 자동조작 금지는 Python·쉘·MCP로 감싸도 달라지지 않는다. 자동조작 대신 허용된 파일·함수 처리와 사용자의 직접 조작을 사용한다. 금지되거나 사용할 수 없는 경로는 미구현 한계로 밝히고 허용된 부분을 완성한다.
