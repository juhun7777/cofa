# 데이터 분석·추천·보고서

원자료를 보존하고 단위·기간·집계 기준·결측·중복·정렬 기준부터 확인한다. 외부 자료·검색·업로드는 실제 허용 범위 안에서만 사용한다.

처리 규칙은 작은 표본에서 사람이 계산할 수 있게 한다. 합계·건수·비율·제외 건수는 원자료와 대조하고, 추천 결과는 후보·제외 이유·동점 처리·선택 이유를 추적할 수 있게 한다. 총점이나 정확도를 근거 없이 꾸미지 않는다.

가능하면 같은 작은 입력에 대해 수계산 또는 별도의 간단한 기준식과 실제 출력을 비교한다. 구현 함수를 다시 호출해 예상값을 만들지 않는다. 모델의 자기평가만으로 정확도를 입증하지 않는다.

보고서는 결론·근거·대안·한계를 연결한다. 사실·가정·해석을 구분하고 숫자·주장의 원본 위치를 찾을 수 있게 한다. 빈 자료, 잘못된 값, 단위 혼동, 필터 변경이 결론에 주는 영향을 과제에 맞춰 확인한다. 복잡한 차트보다 수치와 표의 일관성을 먼저 확보한다.
