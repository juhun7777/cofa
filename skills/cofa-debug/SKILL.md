# 오류를 좁혀 수정하고 같은 조건으로 재검증

현재 단계·남은 시간·허용 도구를 따른다. AI 금지 단계에서는 지원하지 않는다. 오류 메시지·입력·재현 조건·최근 변경을 확인하고, 허용된 가장 작은 실행으로 문제를 재현한다.

관찰과 추측을 구분한다. 입력→파싱→처리→저장·응답→표시 중 어느 경계에서 예상과 달라지는지 좁힌다. 민감정보·시험 데이터를 외부 진단 서비스로 보내지 않는다. 브라우저 자동조작 대신 사용자의 재현 보고와 허용된 로컬 검사를 사용한다.

한 가지 원인 가설에 대해 최소한의 변경을 하고 원래 실패한 조건을 다시 실행한다. 오류를 숨기거나 테스트 기대값을 실제 잘못된 출력에 맞춰 바꾸지 않는다. 독립적인 정답 근거에 문제가 있었던 경우에만 그 근거를 설명하며 수정한다.

같은 문제가 반복되면 추가 패치를 쌓기 전에 가설과 변경을 되짚는다. 짧은 작업의 기본 권고로 한 문제에 약 10분을 넘기기 전에 남은 시간과 필수성을 다시 판단한다. 필수 기능의 오류면 범위를 줄여 해결하고, 선택 기능이면 마지막 작동 상태로 복구하거나 제외한다. 이 시간은 고정 시험 규칙이 아니다.

수정 위치·원인 근거·변경 내용·원래 재현 조건의 결과·남은 한계를 짧게 보고한다. 확인하지 못하면 해결됐다고 선언하지 않는다. 시간 제한 때문에 우회했다면 실제 구현의 한계와 사용자에게 보이는 동작을 명시한다.
